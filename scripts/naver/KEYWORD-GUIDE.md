# 네이버쇼핑 키워드(상품명·태그·속성) 세팅 기준

바로산지 스마트스토어 상품을 등록·수정할 때 지키는 기준을 정리해둔 문서입니다.
코드로 옮긴 검수 규칙은 `src/lib/naver-keyword.ts`에 있고, `npm run naver:lint` 로 돌립니다.

## 0. 먼저 알아야 할 것 — 키워드는 "많이"가 아니라 "안 어기는" 게 먼저

네이버쇼핑 랭킹은 **적합도 · 인기도 · 신뢰도** 세 가지로 매겨집니다.
이 중 상품명 가이드를 어기면 **SEO 스코어 페널티**가 붙는데, 네이버 설명상 이건 매우 강한
조치라서 **다른 정보가 아무리 잘 되어 있어도 랭킹에서 크게 불리해집니다.**

그래서 순서는 이렇습니다:

1. 가이드 위반부터 없앤다 (페널티 제거) ← **효과가 가장 큼**
2. 카테고리·속성을 정확히 맞춘다 (적합도)
3. 그다음에 태그로 유입 경로를 넓힌다

키워드를 욱여넣는 건 3번인데, 1번이 안 된 상태에서 3번만 하면 손해입니다.

## 1. 키워드가 반영되는 순서

검색 노출 가중치는 대략 이 순서입니다:

**상품명 → 카테고리 → 속성 → 태그 → 본문**

상품명이 압도적으로 중요하고, 태그는 "상품명에 못 넣은 키워드를 줍는 용도"입니다.

## 2. 상품명 규칙

### 지켜야 하는 것 (어기면 페널티)

| 항목 | 기준 |
|---|---|
| 길이 | **50자 이내** |
| 중복 단어 | **같은 단어 반복 금지** (브랜드·카테고리명 중복 포함) |
| 홍보 문구 | 최저가·할인·무료배송·사은품·프리미엄·베스트 같은 **수식어 금지** |
| 판매처명 | **쇼핑몰·상호명 금지** (판매처는 네이버가 따로 표시함) |
| 기호 | `( )` `[ ]` `+` `-` `~` `/` `%` `,` `.` **만** 허용. ★♥! 등 금지 |
| 언어 | 한글 기본, 필요할 때 영문. 숫자는 아라비아 숫자 |
| 정확성 | 브랜드·제조사·모델명은 **공식 명칭만**. 색상·수량·속성을 임의로 바꾸지 않기 |

### 권장 조합

```
산지/브랜드 + 상품명(품종) + 상태/용도 + 규격
예) 서해안 수꽃게 국산 찜용 1kg
```

### 확인 방법

스마트스토어 상품 등록/수정 화면의 **[상품명 검색품질 체크]** 버튼을 누르면
현재 상품명이 가이드에 맞는지 네이버가 직접 점수를 보여줍니다. 저장 전에 꼭 눌러보세요.

## 3. 태그 규칙

- 입력은 몇 개든 되지만 **검색에 반영되는 건 10개까지**입니다 → 중요한 것부터 10개
- **네이버 태그사전에 등록된 태그만 실제로 동작합니다.** 태그 입력창에서 검색했을 때
  자동완성으로 뜨는 것만 쓰세요. 사전에 없는 말은 입력돼도 검색에 안 걸립니다
- **상품명에 이미 있는 말은 태그에 또 넣지 마세요.** 이미 잡히는 키워드라 자리만 낭비입니다.
  상품명에 못 넣은 키워드를 태그로 채우는 게 맞습니다
- 수식어(프리미엄, 인기, 최고급)는 빼세요. **사람들이 실제로 검색하는 말**만 넣습니다

### 태그 10칸 채우는 방법

| 유형 | 예시 (꽃게) |
|---|---|
| 품종·상태 | 수꽃게, 활꽃게 |
| 조리법·용도 | 꽃게탕, 꽃게찜, 간장게장용 |
| 시기 | 제철꽃게, 가을꽃게 |
| 산지 | 서해안꽃게, 연평도꽃게 |
| 구매상황 | 손질꽃게, 선물용꽃게 |

## 4. 키워드 고르는 기준

- **네이버 광고 > 키워드도구**에서 검색량을 확인합니다
- 검색량이 너무 큰 키워드(대형 키워드)는 경쟁에서 밀려 노출이 안 됩니다
- 초기에는 **월 검색량 2,000 이하의 세부 키워드** 위주가 유리합니다
- 세부 키워드를 상품명·태그·속성에 나눠 배치합니다

## 5. 카테고리와 속성

- **카테고리가 틀리면 적합도에서 크게 불리합니다.** 예: "활 문어"인데 `건어물` 카테고리에
  들어가 있으면, 검색의도가 아예 다른 자리에 놓이는 셈입니다
- 속성은 카테고리마다 항목이 다르고, **검색 필터로 직접 쓰이기 때문에** 채워야 노출 경로가
  늘어납니다 (좌측 필터에서 걸러질 수 있음)
- 브랜드·제조사 직접 입력은 "미등록" 표시를 없애줄 뿐, **네이버쇼핑 검색에는 반영되지
  않습니다.** 검색 노출을 원하면 카탈로그(모델) 매칭이 필요합니다 — 자세한 건 `README.md`

## 6. 검수 돌리는 법

```bash
npm run naver:lint
```

- API 연동 전: `scripts/naver/products-to-check.json` 에 상품을 채워넣으면 검사합니다
- API 연동 후: `npm run naver:audit` 을 먼저 돌리면 전 상품을 자동으로 검사합니다
- 결과는 `scripts/naver/out/keyword-lint.json`

`[고침필요]` 는 가이드 위반이라 페널티 위험이 있는 것, `[개선권장]` 은 손해는 아니지만
고치면 유입이 느는 것입니다. **고침필요부터 처리하세요.**

## 7. 이 문서의 근거

네이버 공식 가이드(쇼핑 검색 SEO 가이드, 상품명 검색품질 체크 규칙)와 그 해설 자료를
바탕으로 정리했습니다. 네이버가 규칙을 개정하면(예: 상품명 검색품질 체크 규칙 개선)
이 문서와 `src/lib/naver-keyword.ts` 도 함께 고쳐야 합니다.
