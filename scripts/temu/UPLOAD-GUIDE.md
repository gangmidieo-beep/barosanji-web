# 테무 상품 등록 기준 (셀러센터 가이드 정리)

테무 셀러센터의 상품 등록 가이드를 정리한 문서입니다.
**네이버(스마트스토어)와 규칙이 다릅니다.** 같은 상품이라도 상품명·이미지를 따로 만들어야 합니다.

## 0. 네이버와 무엇이 다른가 — 먼저 볼 것

| 항목 | 네이버 | 테무 |
|---|---|---|
| 상품명 길이 | **50자 이내** (넘으면 감점) | 500자 허용, **모바일 80자 권장** |
| 상품명 구조 | 산지+품종+상태+규격 (간결) | **브랜드 + 상세 + 용도 + 유형 + 특징** (설명형) |
| 중복 단어 | **금지** (SEO 페널티) | 명시적 금지 없음 |
| 대표 이미지 텍스트 | 사실상 허용 | **금지** (텍스트·그래픽·워터마크) |
| 태그 | 10개까지 검색 반영 | 태그 개념 없음 |

**네이버 상품명을 테무에 복사하면 설명이 부족해 보이고, 테무 상품명을 네이버에 복사하면 50자를 넘겨 감점됩니다.**

## 1. 상품명

- 500자 이내. **모바일 기준 80자 이내가 이상적**
- **문자·숫자·기호만.** 이모지·특수 서식 금지
- 규칙에 어긋나면 자동 수정되거나 검색에 안 잡힐 수 있음

**권장 구조**
```
[브랜드] + [제품 상세 정보] + [사용 용도/상황] + [제품 유형] + [주요 특징·장점]
```
브랜드가 없으면(= "이 제품에는 브랜드가 없습니다" 체크) 브랜드 자리는 비우고 나머지로 채웁니다.

## 2. 카테고리

- 정확한 카테고리가 노출을 좌우합니다
- 상품명을 넣고 **[카테고리 추천]** 을 누르면 후보를 제안해줍니다
- 못 찾으면 판매자 지원팀 문의

## 3. 제품 설명 (상세 정보)

- **장점을 단락으로 나눠** 쓰기. 한 덩어리로 쓰지 않기
- **AI가 쓴 듯한 어조를 피할 것** — 테무가 명시적으로 요구합니다
- 가장 중요한 특징은 **설명 위에 별도 항목**으로 뽑기
- 변형(옵션)별 차이가 아니라 **상품 전체**를 설명
- **결함·문제점 언급 금지** ("긁힘 있음" 같은 표현)
- 부정확하거나 관련 없는 설명은 추천 노출을 떨어뜨립니다

여기 올린 이미지는 **페이지 중앙**(상세 영상 아래)에 표시됩니다. 상단 이미지가 아닙니다.

## 4. 변형(SKU)

- **SKU가 하나여도 변형 유형을 최소 1개는 골라야 합니다**
- 예: 머그컵 흰색 하나만 팔아도 `color=white` 또는 `material=ceramic`
- 농수산물이면 `weight`(중량) 또는 `size`(크기)를 쓰면 자연스럽습니다

## 5. SKU 이미지 — 여기서 많이 막힙니다

- **페이지 상단**에 SKU별로 표시됩니다 (상세설명 이미지와 다른 자리)
- ⚠️ **이미지에 텍스트·그래픽·워터마크를 넣지 마십시오**
- 흐리거나, 오해를 부르거나, SKU 정보와 안 맞으면 **승인율이 떨어집니다**
- 여러 각도에서 선명하게

> 한국 쇼핑몰 상세이미지는 보통 글자가 잔뜩 박혀 있습니다.
> **네이버에 쓰던 이미지를 그대로 올리면 상단 SKU 이미지에서 걸립니다.**
> 상단에는 글자 없는 제품 사진만, 글자 있는 이미지는 상세설명(중앙)으로 내려야 합니다.

## 6. 포장 크기·무게 — 돈이 걸린 항목

- 판매 전에 **포장 후** 크기와 무게를 입력해야 합니다
- 배송비 계산과 배송 방법 결정에 쓰입니다
- **가격 평가 승인율에 영향을 줍니다**
- ⚠️ **실제와 차이가 크면 배송비 추정이 어긋나 대금이 과도하게 보류될 수 있습니다**

> 공급사 직배송 구조라 실제 박스 규격을 모르면 **공급사에 물어봐야 합니다.**
> 대충 넣으면 정산에서 손해를 봅니다.

## 7. 원산지 (별도 규정)

- 원산지를 **"특정 국가 = Republic of Korea"** 로 고르면
  `Made in Republic of Korea` 라벨이 **실제 제품에 붙은 사진**(제조사명·주소 포함)을 요구합니다
- 신선 농수산물에는 그런 라벨이 없으므로 증빙이 불가능합니다
- → **"상품 상세설명 참조"** 를 고르고, 상세설명에 **원료별 원산지를 모두 글로 명시**합니다

```
[원산지 정보]
· 꽃게 : 대한민국 (연평도)
· 간장 : 대한민국
· 제조 : 대한민국
```

한국 원산지 표시 규정상 **원재료와 생산 공정이 모두 한국일 때만 "한국산"** 입니다.
원료가 수입이면 상품명에도 "국내산"을 쓰면 안 됩니다.

## 8. 등록 전 체크리스트

- [ ] 상품명 80자 이내, 이모지 없음, 브랜드+상세+용도+유형+특징 구조
- [ ] 카테고리 [추천] 눌러 확인
- [ ] 상세설명 단락 구분, 핵심 특징 상단 별도 표기
- [ ] **상세설명에 원산지 명시**
- [ ] SKU 변형 최소 1개 지정
- [ ] **상단 SKU 이미지에 글자 없음**
- [ ] **포장 후 크기·무게 실측값** (공급사 확인)
